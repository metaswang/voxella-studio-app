# Emma and the Little Bird · MossFormer2 48k 试听实验

日期：2026-10-05（新加坡）。输入为 app 会话 `F8C8DAF5-9EC3-4243-BCA7-454763AC7884` 的现有音频，6.961375 秒、24 kHz、单声道、32-bit float WAV。原始文件已复制保存，未修改会话数据。

## 目标与设计

用 app 已有的 MossFormer2-SE FP16 48 kHz 模型，评估是否能改善旁白的清晰度与自然质感。使用同一 `MLXAudioSTS.MossFormer2SEModel.enhance` 实现，经 app 所用的短音频整段推理路径（<20 秒）；通过该库已有 STS CLI 执行，而非从 app UI 发起任务。输入先由 FFmpeg 重采样至 48 kHz，因此重采样实现与 app 的 AVAudioConverter 不完全相同。

模型权重 SHA256 与 app 已安装权重一致：`61e63484df9c2be7e1111ca0346d431422a98b263331021a67c2d7ddb2f67a85`。

| 版本 | 处理 |
| --- | --- |
| A | 原音，仅重采样和响度匹配 |
| B | 100% MossFormer2 整段增强 |
| C | app 同款一阶 80 Hz 高通 → MossFormer2 → 45% 增强 + 55% 高通原声 |
| D | 同上，70% 增强 + 30% 高通原声 |

45% 为 app 听音轨默认混合比例。试听版改用 BS.1770 响度测量和每个文件固定增益，而非 app 的近似 RMS 响度算法；统一为约 −19.94 LUFS。选用该目标是为了保留动态、满足真峰值 ≤ −1.5 dBTP。交付为 48 kHz / 24-bit 无损 PCM WAV。未增加混响、压缩或高频提升。

## 验证与结果

- 两次模型推理均完成，推理耗时分别约 0.99 秒和 0.34 秒（不含编译及模型加载）。
- 100% 样本有限，无 NaN/Inf；四个试听版本时长及样本数一致，334146 样本。模型延迟检查为 0 样本。
- 模型原始输出为 333696 样本，比输入少 450 样本（9.375 ms）；按 app `padOrTrim` 的做法补齐尾部静音。原音最后 450 样本峰值约 −94.15 dBFS，该补齐位于接近静音的尾部。
- A/B/C/D 测量响度分别为 −19.94 / −19.93 / −19.95 / −19.94 LUFS；真峰值为 −1.74 / −1.78 / −1.60 / −1.60 dBTP。
- 纯模型增强 B 与原音波形相关度约 0.999953，增益匹配残差 RMS 为原音 RMS 的约 0.97%。这表示模型改变较小，不证明主观质量提升。
- C 和 D 包含高通处理，因此与原音的差异主要不能归因于增强比例；本实验比较完整制作方案，没有将高通和模型贡献完全隔离。

试听顺序：`ABCD_comparison_48k24bit.wav` 依次 A → B → C → D，版本之间留 0.8 秒空白；总时长 30.2455 秒。

建议先听 C 的自然混合版，再与 A、B 比较字头、齿音、`home` 的尾音和句间停顿。D 用于比较更高增强比例，名称不表示已验证更干净。没有干净参考真值，也没有人类听音评分；本实验未验证“高级感”提升。重采样到 48 kHz 不会恢复源音频缺失的高频。

所有文件在 `audio/`，完整测量见 `results.json`，可复现脚本为 `run.sh`、`experiment.py`。运行需 Swift/MLX、Metal GPU、FFmpeg 与 Python NumPy。
